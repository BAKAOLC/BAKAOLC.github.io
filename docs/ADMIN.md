# 本地站点管理中心

项目内置基于 Vue 3 与 Naive UI 的本地管理中心。它直接读写当前仓库中的 JSON5 和素材文件，不依赖数据库、云端后台或浏览器目录授权。

## 启动

在仓库根目录执行：

```bash
npm install
npm run admin
```

命令会启动：

- 网站预览：`http://127.0.0.1:5173/`
- 管理中心：`http://127.0.0.1:5174/admin/`

日常使用的 `npm run admin` 会自动打开管理中心。自动化测试或只需后台启动管理服务时使用 `npm run admin:ui:no-open`，该命令不会打开浏览器标签页。

管理服务的项目根目录固定为执行命令的仓库，因此不需要选择目录。页面底部会显示当前项目名称、Git 分支和“已绑定当前仓库”状态。管理中心不会自动执行 Git 提交或推送。

## 页面结构

管理界面按职责分层：

- 内容管理：图库作品、文章、角色档案。
- 结构与关系：角色索引、图库标签、文章分类、友链体系。
- 站点呈现：首页与个人资料、站点名称、SEO、语言、文章页卡片。
- 功能与体验：功能开关、背景音乐、Live2D 挂件和运行时。
- 外部集成：Giscus、FontAwesome 与站点识别规则。
- 素材库：图片、音频、视频、文档和其他源素材。

条目型内容使用“条目列表 + 编辑器”双栏布局；复杂数据使用可折叠的正式层级，例如角色档案中的“角色 → 差分 → 图片 → 信息卡片”。窄屏设备使用遮罩式侧栏。

### 集合文件管理

图库作品、文章和角色档案提供完整的源文件生命周期管理：

- 新建时分别指定 JSON5 文件名和配置 ID，首次保存不会覆盖同名文件；
- 搜索、刷新、复制条目、重命名文件和永久删除；
- 文件名、配置路径与 ID 在界面中分别显示，重命名文件不会暗中修改 ID；
- 文件修改时间冲突和同集合 ID 冲突会阻止写入；
- `Ctrl+S` / `Cmd+S` 快捷保存，以及切换模块、刷新或关闭页面前的未保存拦截。

## 多语言编辑

页面右上角提供“中文 / EN / 日本語”切换。编辑区一次只显示当前语言，不会同时堆叠多个语言字段。

保存时仍使用项目原有 `{ zh, en, jp }` 对象结构。原配置中的单字符串写法也会在读取时兼容，并在实际编辑后展开为多语言对象。

## 素材上传

图片和文件字段中的“素材库”按钮会打开统一素材弹窗，其中包含：

- 文件名和目录搜索；
- 图片、音频、视频、文档类型过滤；
- 目录过滤，以及按路径、文件名、修改时间或大小排序；
- 图库、角色、文章、背景、友链、音频等上传目标；
- 自定义 `public/assets` 子目录；
- 外部文件可拖放到当前目录，也可直接投放到目录树、面包屑或文件夹条目；
- 管理器内的文件可直接拖入其他文件夹完成移动，内部拖拽不会被识别为上传；
- 批量选择上传；
- 文件重名时自动添加数字后缀。
- 复制公开路径、创建素材副本、重命名或移动素材，以及带引用风险提示的永久删除。

拖拽移动与“移动或重命名”使用相同的文件操作规则，不会自动改写配置中已有的旧路径引用；完成后界面会明确提示这一点。

`public/assets/thumbnails` 是构建生成目录，管理 API 会在扫描和上传两端过滤它，因此不会出现在素材库，也不能成为上传目标。

## 数据安全与兼容性

- 管理 API 只监听 `127.0.0.1`，并校验写入请求来源。
- 配置读写限制在明确的 JSON5 白名单和内容子目录中。
- 素材写入限制在 `public/assets`，同时拒绝路径穿越和生成目录。
- 配置采用临时文件加原子替换写入。
- 保存时会比较文件修改时间；外部程序修改过文件时返回冲突，而不是覆盖。
- 图库、文章和角色档案写入前经过共享 Zod 规则验证。
- 网页运行时继续读取原有配置格式，与管理中心解耦。
- 集合构建脚本继续兼容旧的单文件对象和单文件数组。

根目录自动生成的 `images.json5`、`articles.json5` 和 `character-profiles.json5` 不应手工编辑；管理源位于对应子目录中。

## 检查

检查管理中心：

```bash
npm run admin:check
```

检查整个项目：

```bash
npm run ci:check
```

前者会执行管理端类型检查、全部现有配置的字段覆盖与 JSON5 往返测试，以及管理端生产构建。
