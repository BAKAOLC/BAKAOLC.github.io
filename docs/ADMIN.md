# 本地站点管理中心

管理中心用于在本机编辑站点配置和素材。它直接保存到当前仓库，不需要数据库，也不会自动提交或推送 Git 改动。

## 启动

在仓库根目录运行：

```bash
npm install
npm run admin
```

启动后可访问：

- 站点预览：`http://127.0.0.1:5173/`
- 管理中心：`http://127.0.0.1:5174/admin/`

`npm run admin` 会自动打开管理页面。如果不希望自动打开浏览器，使用 `npm run admin:ui:no-open`。

## 使用方式

左侧导航按内容、关系、站点呈现、功能和外部集成分类。图库、文章和角色档案使用“条目列表 + 编辑区”，其他页面直接编辑对应配置。

- `Ctrl+S` / `Cmd+S`：保存当前配置。
- 拖动列表把手：调整条目或图片顺序。
- 右键条目：显示适合当前内容的复制、移动、替换或删除操作。
- 切换页面或关闭窗口时，未保存的修改会收到提示。

图库、文章和角色档案可以新建、复制、重命名和删除独立的 JSON5 文件。文件名和配置 ID 是两个不同概念，重命名文件不会修改 ID。

## 多语言内容

右上角切换管理界面的语言；编辑区内的“内容语言”用于选择当前正在填写的中文、英文或日文内容。

每次只显示一种语言，保存时仍保持项目原有的多语言配置格式。

## 文件管理器

点击图片或文件字段中的“文件管理器”即可打开素材库。它支持：

- 文件夹树、网格和列表视图；
- 搜索、类型筛选和排序；
- 批量上传、新建文件夹、复制、移动、重命名和删除；
- 将外部文件拖到当前目录或指定文件夹上传；
- 将管理器内的文件拖入其他文件夹移动；
- 右键操作，以及触屏长按菜单。

输入框和文本编辑区仍使用浏览器原生右键菜单，方便复制和粘贴。

## 使用注意

- 移动或重命名素材不会自动修改配置中已经保存的旧路径引用。
- `public/assets/thumbnails` 是自动生成目录，不需要手动管理。
- `images.json5`、`articles.json5` 和 `character-profiles.json5` 是聚合结果，请编辑各自子目录中的源文件。
- 如果文件已被其他程序修改，管理中心会阻止直接覆盖并提示重新加载。

## 检查

检查管理中心：

```bash
npm run admin:check
```

检查整个项目：

```bash
npm run ci:check
```
